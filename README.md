# Weather App (API)

A desktop weather lookup app with a Tkinter GUI, fetching live data from the OpenWeatherMap API.

## What it does
Enter a city name and get current weather conditions displayed in a simple GUI window.

## Tech
- Python
- Tkinter
- requests

## Setup
> ⚠️ This project currently has an API key hardcoded in `main.py`. Before running it yourself, replace it with your own OpenWeatherMap API key, ideally loaded from an environment variable rather than committed to the code.

## Run
```bash
pip install requests pillow
python main.py
```
